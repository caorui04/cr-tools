前置：Node.js ≥ 18 · Python 3.11（勾选 Add to PATH）

# 1) 一键装依赖（DSH + Python 依赖 + 配置 + profile）
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1

# 2) 下载模型（国内镜像优先）

# 3) 编辑 pipeline\config.yaml 填 Key（§四）
# 4) 启动

八常见问题

❓ start.bat 闪退？ → 手动运行 pipeline\.venv\Scripts\python.exe -m server.main 看报错

❓ OCR 报 Paddle 无法打开模型？ → 缓存路径含中文自动转 8.3 短路径；仍失败设 PADDLE_PDX_CACHE_HOME 到纯英文目录

❓ lite 没下模型就启动？ → 管线可用、OCR/检索降级；补下模型后重启

❓ 检索 score 恒 0？ → 向量库未建——提交文档入库后 M4 自动索引（需 8083 在线）

❓ 端口被占用？ → 已有实例在跑（重复启动）；关旧的再启动，或改端口

❓ 完全不懂命令行？ → 用方式 A full 包：解压 → 双击 start.bat，全程零命令行
